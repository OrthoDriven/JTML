### (a) Named-graph registry: wire it or delete it? → **DELETE (recommendation)**

**Evidence (P1 — the registry is a phantom API; it was already half-deleted):**
- Declarations live in `include/coordinator/optimizer_stage_script.h:144-168` (`StageGraph`, `ListStageGraphs`, `StageGraphByName`, `ReservedStubGraphNames`), but **the definitions no longer exist in any source file**. `src/coordinator/optimizer_stage_script.cpp` ends at line 197 with `ReservedStubGraphNames()`; grep of the whole repo finds the definitions only in the stale snapshot `repomix-output.xml:4016-4034` (`JtmlProductionGraph` at 3847). The only live caller set is `test/unit/test_stage_script.cpp:410-452` (not built — 0 tests registered per AGENTS.md) and docs (`docs/optimizer-stage-graphs.md:85-112`, still describes the registry as functional). Rebuilding the test tree would produce link errors for `ListStageGraphs`/`StageGraphByName`.
- Expressiveness check: `StageGraph{name, stages}` is a strict subset of what `BuildStageScript` already produces (same `StageScript` type, `optimizer_stage_script.h:144-147`). It cannot express `ObjectiveSpec`, optimizer options, resource bundles, or directive/frame-selection — the things the owner's declarative graph must carry. Wiring it now would add a second source of truth for run shape with zero added power, exactly the "buffered, not removed" anti-pattern.
- Even the header's own comment frames it as a transitional mirror of `CostFunctionManager::listCostFunctions` (`optimizer_stage_script.h:8-17`) — a legacy echo, not a design.

**Recommendation:** DELETE `StageGraph`, `ListStageGraphs`, `StageGraphByName`, `ReservedStubGraphNames` from the header (and the orphaned registry tests + stale docs section). The future declarative registration graph should be a *data format read by the runtime/binder* (typed stage definitions incl. `ObjectiveSpec` + optimizer options + resource bundle ids), not a compiled C++ list that returns a `StageScript` BuildStageScript already computes. `BuildStageScript` remains the single live script source until the declarative graph replaces it (then BuildStageScript → DELETE, subsumed).

### (c) What replaces `DeriveStageCostParams` → **ObjectiveSpec, but only after the never-synced mirror is fixed**
